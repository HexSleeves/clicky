## Affected surfaces (no live URLs — native macOS app)

- **Senior-side menu bar app** — one-button "I need help" trigger, consent dialog, sharing-status indicator, one-tap stop.
- **Kid-side menu bar app (same binary, role-switch mode)** — pair code generator, kid-side preview window, click-to-point on snap, async queue review.
- **Cloudflare Worker** — `/signal/:pairId` (DO-backed), `/pair/generate`, `/pair/verify`, `/turn-credentials`.

## Key interactions to verify

- **First-launch role pick** (kid + senior, two separate Macs)
- **Pairing happy path** (kid generates 6-digit code, senior types it, both see "paired ✓")
- **Help-button core flow** — Mom's button press → consent dialog → kid notification → kid accept → snap delivered to kid → kid clicks on snap → cursor flies on Mom's screen
- **Stop sharing mid-session** — Mom hits stop, both sides tear down cleanly
- **Async fallback** — kid doesn't accept within 60s, snap+audio recorded locally, kid reviews queue later
- **Audio session ownership** — push-to-talk active → start remote help → PTT visibly suspended → end → PTT re-armed without "mic in use" error
- **Blocklist** — Mom is on a bank app when she presses help → snap blocked, kid sees "paused — financial app detected"
- **Multi-monitor** — Mom has 2 displays, kid sees per-display previews, click on display 2 maps to display 2 coordinates

## Edge cases

- **Pair code typo** (≤5 retries before short lockout) → friendly error
- **Pair code expired** (5 min default) → senior sees "ask kid for new code"
- **Pair code brute force** → Worker rate limit kicks in after N attempts/min
- **Pair token replay** → Worker rejects reused tokens
- **WebRTC ICE failure** → TURN fallback path, no user-visible failure
- **TURN credentials expire mid-session** → automatic re-fetch + reconnect
- **Data channel closes mid-session** → 10s reconnect window, then graceful end
- **Kid Mac sleeps mid-session** → graceful detection on resume
- **Snap encode fails (memory pressure)** → retry once, downgrade resolution, surface to kid
- **TCC permission revoked on Mom's Mac** → detect on next launch, kid dashboard shows "Mom needs to re-grant Screen Recording"
- **macOS upgrade resets TCC silently** → `WindowPositionManager` self-check on launch detects, alerts kid
- **Audio device unplugged mid-session** → fall back to default, notify both sides
- **Consent timeout** — Mom doesn't respond within 30s → auto-cancel, kid sees "Mom didn't accept"
- **Async recording fails (disk full)** → surface to kid as "couldn't capture", queue empty
- **Re-pairing** — kid replaces machine → senior re-pairs with new code, old session keys revoked
- **DPI / scaling math** — Retina 2x kid Mac → non-Retina 1x senior Mac, click coordinate must land on the same pixel Mom sees
- **Forward-compatibility** — wire protocol v1 receives an unknown JSON field, ignores it without crashing
- **Malformed JSON on data channel** — log, drop, do not crash
- **Persistence corruption** — RoleManager state file corrupted → fall back to fresh role pick

## Critical paths (must work end-to-end before week-3 ship-to-friends)

1. **Founder dogfood path:** install single binary on founder's Mac and founder's parent's Mac, both pick roles, pair, run one full help-session including snap delivery + cursor flight + audio loop + clean teardown. ≥ 5 successful sessions on N=2 households before scale.

2. **Friend-with-parent path:** friend installs both halves on their own machines (kid-side) and parent's machine (senior-side, in person), pair via 6-digit code, complete one help session unaided by founder.

3. **TCC permission story:** install on a clean macOS install + a freshly-upgraded macOS install. All required permissions (Screen Recording, Microphone, Notifications) successfully granted via the kid-installs-in-person checklist.

4. **Network adversity:** test on at least one symmetric-NAT residential network (likely a parent's home network). TURN relay path verified to work.

5. **Trust integrity:** verify zero data leaks when Mom's active app is a known-bad bundle ID (banking, password manager). Verify the consent dialog cannot be bypassed by any keyboard shortcut.

## Acceptance gate before ship-to-friends

- 35/35 paths in the design doc's Phase 1 Test Plan have passing tests
- 0 critical gaps (no test + no error handling + silent failure) — confirmed in design doc Failure modes table
- TURN relay rate < 50% on test households (else re-architect networking)
- Average end-to-end latency for help-button → cursor-on-Mom-screen < 2 seconds (consent + handshake + snap + click + cursor) on residential broadband
